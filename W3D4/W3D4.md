* **Quantisation:** AWQ
* **GPU:** NVIDIA T4

* **Max model length:** 4096

* **Tool-call parser:** Hermes
* **Auto tool choice:** Enabled

## AWQ Launch Configuration

The AWQ model was launched with:

```text
--model Qwen/Qwen2.5-1.5B-Instruct-AWQ
--dtype half
--max-model-len 4096
--gpu-memory-utilization 0.85
--quantization awq
--enable-auto-tool-choice
--tool-call-parser hermes
```

---

## Performance Results

### GPU VRAM

| Model |   GPU VRAM |
| ----- | ---------: |
| FP16  | 11,581 MiB |
| AWQ   | 11,723 MiB |

The measured VRAM usage was very similar between AWQ and FP16 in this serving configuration. AWQ used approximately **142 MiB more VRAM** during the measurement, while still remaining comfortably within the available GPU memory.

### Generation Speed

| Model | Tokens/s |
| ----- | -------: |
| FP16  |     56.7 |
| AWQ   |    33.71 |

In this test, **FP16 generated tokens faster than AWQ**. Therefore, the original prediction that AWQ would be faster was not supported by the measured result.

---

## Quality Spot Check

Five prompts were used to compare FP16 and AWQ.

The AWQ model performed well on several basic tasks, including summarisation, sentence refactoring, and deployment rollback instructions. However, some degradation was observed compared with FP16, particularly in instruction following and the explanation of quantisation.

Despite these differences, the quantised model successfully passed the official function-calling smoke test.

## Model Decision

### Locked Model

`Qwen/Qwen2.5-1.5B-Instruct-AWQ`

### Quantisation

`AWQ`

### Why this model was locked

The AWQ model passed the official function-calling smoke test with **10/10**, including **2/2 call-free distractor cases**, and provided sufficient GPU memory headroom for the serving workload.

## Prediction vs Reality

| Metric            | Prediction     | Actual Result                               | Correct? |
| ----------------- | -------------- | ------------------------------------------- | -------- |
| AWQ VRAM vs FP16  | About the same | 11,723 vs 11,581 MiB                        | Yes      |

### Key takeaway

AWQ successfully passed the most important reliability gate, especially function calling, but it did **not** provide the expected speed improvement in this particular benchmark. Its measured VRAM usage was also very close to FP16.
